# Tamkeen – AI-Powered Accessible Learning Platform

Tamkeen is an AI-powered educational platform designed to provide an inclusive learning experience for people with disabilities.
The platform integrates artificial intelligence, accessibility technologies, and personalized learning tools to support users with visual, auditory, and physical impairments.

Tamkeen aims to remove barriers in digital education by offering intelligent assistance, voice-based interaction, and adaptive learning recommendations.

---

## Overview

The system provides an accessible learning environment where users can interact with courses using voice commands, receive personalized recommendations, and navigate the platform through assistive technologies.

The platform combines modern web technologies with artificial intelligence models to create an adaptive and inclusive educational system.

---

## Key Features

### Accessibility Support

* Text-to-Speech for reading platform content aloud
* Speech-to-Text for voice-based input and navigation
* Voice command support for hands-free interaction
* Customizable visual settings for improved accessibility

### AI-Powered Personalization

* Intelligent course recommendation system
* Personalized learning roadmaps based on user interests
* Adaptive content suggestions

### Learning Management

* Course and session management
* Integrated quizzes and progress tracking
* Structured learning paths

### Interactive Tools

* AI chatbot for user assistance
* Voice-assisted navigation
* Real-time feedback and progress monitoring

## System Architecture

The platform follows a modular architecture consisting of:

* Backend built with Django for handling APIs, authentication, and business logic
* AI modules responsible for recommendation and voice interaction
* Separate frontend interface for user interaction
* PostgreSQL database for storing users, courses, quizzes, and recommendations
